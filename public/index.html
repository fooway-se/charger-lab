Certificate settings

Use the URL host when its name matches the CSMS certificate. For Docker service routing, the TLS server name can differ from the service address.

NETWORK CHECK

Test CSMS connection

Opens a WebSocket and checks TLS, authentication, and the OCPP 2.0.1 subprotocol. It does not send BootNotification.

In Docker, localhost means this container. For a CSMS in another Compose project, attach both app and station-worker to its network and use its service name and container port. For a host CSMS, use host.docker.internal. The TLS certificate must match the URL host and its CA must be trusted.
